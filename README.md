# سوقنا سوريا

منصة إعلانات مبوّبة عربية لسوريا، تتضمن نسخة الويب وخريطة أولية لتطبيق Expo.

## المحتويات

- `webserver/`: تطبيق الويب الكامل مع الخادم وقاعدة البيانات والمصادقة ولوحة المدير.
- `mobile/`: تطبيق Expo المتوافق مع الهاتف.

## التشغيل المحلي

1. انسخ ملف الإعدادات النموذجي إلى ملف بيئة محلي.
2. أضف متغيرات Manus OAuth وقاعدة البيانات محليًا، ولا ترفعها إلى GitHub.
3. ثبّت الاعتماديات عبر `pnpm install` داخل المجلد المطلوب.
4. شغّل `pnpm run dev` للويب.

## الأمان

لا يحتوي هذا المستودع على مفاتيح API أو كلمات مرور أو رموز JWT أو إعدادات اتصال قاعدة البيانات. تُدار هذه القيم عبر أسرار بيئة النشر.
