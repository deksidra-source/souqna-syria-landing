# سوقنا سوريا للموبايل

تطبيق Expo أولي باللغة العربية والاتجاه من اليمين إلى اليسار. يوفر تبويبات الرئيسية والبحث والنشر وإعلاناتي والحساب، مع طبقة لقراءة الإعلانات العامة من منصة سوقنا عند ضبط عنوان الخدمة المنشورة.

## التشغيل المحلي

1. عنوان الخدمة المنشورة مضبوط حاليًا على `https://souqnasyr-kumzt8ow.manus.space` داخل `src/api.ts`.
2. شغّل `pnpm install` ثم `pnpm start`.
3. افتح التطبيق عبر Expo على جهاز Android أو iPhone.

## حالة التكامل

التصفح والبحث والتفاصيل مصممة لاستهلاك الإعلانات العامة من خدمة tRPC. يتطلب تسجيل الدخول والنشر وإعلانات المستخدم في الدفعة التالية إضافة تدفق OAuth مخصص للموبايل واستبدال واجهات الحالة المؤقتة بهذه الإجراءات المحمية.

الإعلانات المميزة والدفع الإلكتروني مؤجلان عمدًا حتى إنشاء حساب تاجر واختيار مفاتيح بيئة الاختبار؛ لا يؤثر ذلك في النشر المجاني أو نتائج البحث العادية.
