# فهرس حزمة الأرشيف المنظم

سيتم إنشاء مجلد أرشيف قابل للتحميل يجمع الملفات الضرورية للمالك فقط، مع استبعاد كلمات المرور والمفاتيح وقاعدة البيانات الحية ومجلدات المكتبات والسجلات.

يضم الأرشيف مجلدات للشيفرة المصدرية، أدلة التشغيل والنشر، حزم صفحة الهبوط، وقائمة الروابط والحسابات التي يتولاها المالك.
