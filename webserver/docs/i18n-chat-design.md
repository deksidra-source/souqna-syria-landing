# تصميم اللغات والدردشة: سوقنا سوريا

## اللغات والاتجاه

تدعم الواجهة ثلاث لغات: العربية (`ar`) والإنكليزية (`en`) والتركية (`tr`). تعتمد العربية اتجاه **RTL**، بينما تستخدم الإنكليزية والتركية اتجاه **LTR**. تُترجم عناصر الواجهة الثابتة فقط في هذه الدفعة؛ ولا تُترجم عناوين الإعلانات أو وصفها تلقائيًا، كي يبقى نص المعلن الأصلي دقيقًا ولا يضاف محتوى مولد غير موثق.

يحفظ اختيار اللغة محليًا في المتصفح وفي التطبيق، ويطبّق على واجهة الاستكشاف والحساب والنشر والدردشة. عند عدم وجود اختيار سابق، تبدأ المنصة بالعربية.

## نموذج الدردشة

تُنشأ المحادثة حول **إعلان واحد** بين طرفين فقط: مالك الإعلان ومستخدم مهتم. لا يستطيع المالك مراسلة نفسه، ولا يستطيع أي مستخدم ثالث قراءة المحادثة أو إرسال رسالة إليها. يعاد استخدام المحادثة الموجودة لنفس المعلن والمشتري والإعلان بدل إنشاء نسخ متكررة.

| الكيان | الغرض |
|---|---|
| `listing_conversations` | يربط الإعلان بالمالك والمشتري، ويحتفظ بآخر نشاط لكل محادثة |
| `conversation_messages` | يخزن نص الرسالة والمرسل ووقت الإرسال ووقت القراءة |

تقبل الرسائل النصية فقط في النسخة الأولى، بطول محدود ومتحقق منه على الخادم. تظهر واجهة «رسائلي» للمستخدم محادثاته فقط، مع عدد الرسائل غير المقروءة. عند إرسال رسالة جديدة إلى المعلن، يسجّل النظام تنبيهًا داخل الحساب.

## تدفق المستخدم

1. يفتح المشتري إعلانًا منشورًا ويضغط «مراسلة المعلن».
2. يسجّل الدخول إن لم يكن مسجّلًا، ثم ينشأ أو يعاد فتح الحوار الخاص بذلك الإعلان.
3. يرسل رسالة؛ يحدّث الخادم وقت نشاط المحادثة ويضيف تنبيهًا للمستلم.
4. يعرض كل طرف قائمة محادثاته، ولا تظهر رسالة أو محادثة لأي طرف ثالث.
