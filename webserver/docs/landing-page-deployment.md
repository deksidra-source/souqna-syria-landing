# نشر صفحة هبوط «سوقنا سوريا» مجانًا

## الرابط الجاهز الآن

صفحة الهبوط منشورة أصلًا داخل الموقع الحالي على:

<https://souqnasyr-kumzt8ow.manus.space/app>

هذا هو المسار الموصى به الآن؛ لا يحتاج حسابًا جديدًا، ويحافظ على رابط واحد للموقع والإعلانات والخصوصية والدعم.

## خيار GitHub Pages المجاني

استخدم GitHub Pages فقط إذا أردت رابطًا مستقلاً إضافيًا للصفحة. أنشئ حساب GitHub شخصيًا، ثم مستودعًا عامًا باسم مثل `souqna-syria-landing`. في إعدادات المستودع افتح **Settings → Pages**، واختر فرع النشر والمجلد الذي يحتوي `index.html`، ثم احفظ. GitHub Pages يستضيف ملفات HTML وCSS وJavaScript الثابتة من المستودع؛ وفي GitHub Free ينبغي أن يكون المستودع عامًا عند استخدام Pages. [1] [2]

لا تضع في المستودع مفاتيح API أو كلمات مرور أو ملفات `.env` أو بيانات مستخدمين. جميع الصفحات المنشورة تكون عامة، وتوضح GitHub أن عنوان IP للزائر يُسجل لأغراض الأمان. [1]

## خيار Vercel

Vercel خيار جيد لمعاينات تلقائية من مستودع GitHub: يربط المستودع ثم ينشر التحديثات عند كل push. لكن خطة Hobby مخصصة للاستخدام الشخصي وغير التجاري وفق وثائق التسعير؛ لذلك لا أنصح باعتبارها استضافة تشغيلية نهائية لمنصة إعلانات تجارية. [3] [4]

## ما أحتاجه منك للنشر الخارجي

لا أحتاج كلمة المرور. أنشئ حساب GitHub ثم مستودعًا عامًا فارغًا، وقل لي اسم المستخدم واسم المستودع فقط. عندها أجهز محتوى صفحة ثابتة مناسبًا للتصدير وأرشدك إلى خطوة الربط التي تؤكدها أنت داخل حسابك.
