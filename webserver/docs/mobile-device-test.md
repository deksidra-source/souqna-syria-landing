# اختبار تطبيق سوقنا سوريا على الأجهزة

## الهدف

يهدف هذا الدليل إلى اختبار نسخة Expo على جهاز Android أو iPhone فعلي قبل تجهيزها للمتاجر. تغطي هذه الجولة التصفح والبحث واللغات والصور والموقع والانتقال الآمن إلى النشر والرسائل في المنصة المنشورة.

## قائمة الفحص

| التدفق | النتيجة المتوقعة |
|---|---|
| فتح التطبيق | ظهور الواجهة العربية RTL دون قص في العنوان أو شريط التبويب |
| اختيار English أو Türkçe | تغير النصوص الأساسية واتجاه الصفوف إلى LTR مع بقاء العناصر قابلة للقراءة |
| الصفحة الرئيسية | ظهور الإعلانات المنشورة أو حالة واضحة إن لم توجد بيانات |
| البحث والقسم | جلب نتائج متوافقة مع عبارة البحث أو القسم المختار |
| تفاصيل الإعلان | ظهور العنوان والوصف والسعر والصور والموقع عندما تكون متاحة |
| نموذج النشر | طلب إذن الصور والموقع عند الاختيار، مع إظهار حالة الإذن بوضوح |
| النشر وإعلاناتي | فتح صفحة المنصة المنشورة للمصادقة والنشر الآمن إلى حين اكتمال OAuth الأصلي |
| الرسائل | فتح صفحة الرسائل المنشورة وتسجيل الدخول، ثم بدء محادثة من إعلان يملكه مستخدم آخر |

## ما يجب الإبلاغ عنه

سجّل نوع الجهاز وإصدار النظام واللغة المختارة ولقطة شاشة عند حدوث مشكلة. يجب عدم استخدام حساب المعلن نفسه لبدء محادثة حول إعلانه، ويجب التحقق من وصول التنبيه داخل الحساب إلى الطرف الآخر عند إرسال رسالة.

> لا تُرسل مفاتيح دفع أو كلمات مرور أو صورًا لوثائق شخصية داخل التطبيق خلال الاختبار.
