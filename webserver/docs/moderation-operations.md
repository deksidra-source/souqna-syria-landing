# تشغيل البلاغات والدعم وطلبات حذف البيانات

## الغرض

توثق هذه الصفحة الإجراء التشغيلي لمنصة «سوقنا سوريا» عند استلام بلاغ عن إعلان أو رسالة، أو تذكرة دعم، أو طلب حذف بيانات. وهي سياسة تشغيل داخلية وليست بديلًا عن الاستشارة القانونية أو عن اعتماد مالك المشروع للنصوص القانونية المنشورة.

## قنوات الاستلام

| الطلب | طريقة الإرسال | التخزين | الإشعار |
|---|---|---|---|
| بلاغ إعلان أو رسالة | زر «إبلاغ» في الويب | `content_reports` | يُراجع من لوحة قاعدة البيانات |
| حظر مستخدم | زر الحظر في الدردشة | `user_blocks` | يفرض الخادم قطع المحادثة بين الطرفين |
| تذكرة دعم | صفحة `/support` | `support_requests` | إشعار إلى مالك المشروع |
| حذف بيانات | صفحة `/support` للمستخدم المسجل | `data_deletion_requests` | إشعار إلى مالك المشروع |

## إجراء المراجعة

يفتح المسؤول قاعدة بيانات المشروع من لوحة الإدارة ويفرز الصفوف ذات الحالة `open` يوميًا. يراجع البلاغ مع سياقه، ثم يختار قرارًا متناسبًا: أرشفة الإعلان أو إيقافه، أو تقييد حساب مخالف، أو حفظ البلاغ مع تبرير رفضه. لا تُكشف هوية المبلّغ للطرف الآخر.

تُراجع طلبات حذف البيانات بعد التحقق من الحساب وصلاحية الطلب. لا يُنفّذ حذف فوري قد يكسر سجل معاملات أو حقوق مستخدمين آخرين أو التزامات قانونية. يوثّق المسؤول القرار وتاريخه في الحقل التشغيلي المناسب قبل اعتبار الطلب منجزًا.

## معايير أولوية مبسطة

| المستوى | أمثلة | الإجراء الأولي |
|---|---|---|
| عاجل | تهديد، استغلال، نشاط غير قانوني محتمل | حجب المحتوى أو الحساب مؤقتًا ومراجعة فورية |
| عالٍ | احتيال، انتحال، تحرش متكرر | مراجعة خلال يوم عمل، وحظر/إيقاف عند التحقق |
| عادي | محتوى مضلل أو رسالة مزعجة | مراجعة خلال يومي عمل وإبلاغ القرار عند الحاجة |
| دعم أو حذف | سؤال حساب أو طلب بيانات | تأكيد الاستلام ومراجعة بحسب هوية الحساب |

## حدود النظام الحالية

الإشعار يصل إلى مالك المشروع عند تذكرة الدعم أو طلب الحذف. أما قائمة البلاغات وسجل الطلبات فيظهران في قاعدة بيانات المشروع للمالك/المسؤول. قبل الإطلاق العام واسع النطاق، يُفضّل تخصيص مسؤول محتوى ووقت استجابة معلن وبريد دعم رسمي بعد اعتماد المالك للنصوص القانونية.
