# بنية النسخة الأولية: سوقنا سوريا

## الغرض والنطاق

تعمل النسخة الأولية كمنصة إعلانات مبوبة عامة باللغة العربية، مهيأة للاتجاه من اليمين إلى اليسار. يستطيع الزائر استكشاف الإعلانات المنشورة والبحث فيها، بينما يستطيع المستخدم المسجل إنشاء إعلاناته وإدارتها ومتابعة التنبيهات الخاصة بها. تُطلق المنصة خمسة أقسام موحّدة: **العقارات، السيارات، الوظائف، المنتجات المستعملة، والخدمات**.

## خريطة المسارات

| المسار | الغرض | الوصول |
|---|---|---|
| `/` | صفحة الاستكشاف، الأقسام، البحث السريع، والإعلانات الأحدث | عام |
| `/ads` | نتائج البحث والفلاتر حسب القسم والمحافظة والسعر | عام |
| `/ads/:id` | تفاصيل الإعلان والصور والموقع وبيانات المعلن | عام |
| `/publish` | نموذج نشر أو تعديل إعلان بالحقول الديناميكية | مستخدم مسجل |
| `/my-listings` | قائمة إعلانات المستخدم وإدارة حالتها | مستخدم مسجل |
| `/notifications` | تنبيهات النشر وتغير الحالة والاهتمام | مستخدم مسجل |

## تدفقات الاستخدام

| الشخصية | التدفق الأساسي | النتيجة |
|---|---|---|
| الزائر | الصفحة الرئيسية ← بحث/قسم ← فلاتر ← تفاصيل الإعلان | يعثر على إعلان ويصل إلى بيانات التواصل المعروضة من صاحبه |
| المستخدم المسجل | تسجيل الدخول ← نشر إعلان ← اختيار القسم ← تعبئة الحقول المتغيرة ← إضافة الصور والموقع ← إرسال | ينشأ الإعلان بحالة `published` افتراضيًا ويظهر في لوحة «إعلاناتي» مع تنبيه داخل الحساب |
| المعلن | «إعلاناتي» ← تعديل/إيقاف/أرشفة/حذف ← عرض التنبيهات | يدير إعلاناته فقط؛ كل تغير حالة يُسجل في التنبيهات داخل التطبيق |
| المهتم | تفاصيل إعلان ← حفظ أو إظهار وسيلة الاتصال | يسجل اهتمامًا فريدًا، ويتلقى صاحب الإعلان تنبيهًا داخل حسابه |

## طبقات النظام

| الطبقة | المسؤولية |
|---|---|
| الواجهة | واجهة React عربية RTL، صفحات عامة، نموذج نشر ديناميكي، واجهات إدارة المعلن، وحالات التحميل والخطأ والفراغ |
| واجهة الخدمة | إجراءات tRPC للتحقق من المدخلات، البحث، إنشاء/تعديل/حذف الإعلانات، رفع الصور، وإدارة الاهتمامات والتنبيهات |
| قاعدة البيانات | جداول `listings` و`listing_images` و`listing_interests` و`notifications` المرتبطة بحسابات `users` |
| تخزين الوسائط | حفظ صور الإعلان في التخزين الكائني، مع حفظ المفتاح والرابط والرتيب فقط في قاعدة البيانات |
| الخرائط | اختيار إحداثيات الموقع وعرضها باستخدام المكوّن المضمّن، دون تخزين عنوان تفصيلي حسّاس ما لم يختَره المعلن |

## قواعد التشغيل الأساسية

يكون الإعلان **منشورًا** عند إنشائه في هذه النسخة، مع إتاحة حالات المسودة والإيقاف المؤقت والأرشفة. لا يمكن للمستخدم تعديل أو حذف إعلان لا يملكه. لا تُخزَّن ملفات الصور في قاعدة البيانات؛ بل تحفظ مراجعها فقط. ويقتصر التنبيه في النسخة الأولية على مركز تنبيهات داخل الحساب، مع إمكانية تطويره لاحقًا إلى إشعارات فورية أو بريدية بعد إضافة قناة مناسبة للمستخدمين النهائيين.
