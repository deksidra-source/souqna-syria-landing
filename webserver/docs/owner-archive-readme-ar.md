# أرشيف سوقنا سوريا للمالك

## ابدأ من هنا

هذا الأرشيف يجمع نسخًا منظمة من الملفات المهمة لمشروع «سوقنا سوريا». احتفظ به في Google Drive أو ذاكرة خارجية خاصة، ولا ترفعه إلى مستودع عام ولا ترسله في مجموعات عامة.

## محتويات الأرشيف

| المجلد | المحتوى | الاستخدام |
| --- | --- | --- |
| `01_ابدأ-هنا` | هذا الفهرس وقائمة الروابط المهمة | معرفة ما تفعله بكل ملف وحساب |
| `02_الشيفرة-المصدرية` | كود الويب والخادم وتطبيق Expo | حفظ ملكية المشروع أو تسليمه لمطور موثوق |
| `03_صفحة-الهبوط` | نسخ صفحة الهبوط وحزم تحديث Netlify | تحديث صفحة الترويج عند الحاجة |
| `04_الأدلة` | أدلة النشر، التطبيقات، الدعم، الخصوصية، التسويق، والدخل | الرجوع إلى الخطوات دون الحاجة إلى البرمجة |

## ما لا يوجد داخل الأرشيف

لم تُضمَّن كلمات مرور أو رموز تحقق أو مفاتيح API أو بيانات قاعدة البيانات الحية أو صور المستخدمين أو ملفات السجل أو مجلدات المكتبات. هذه الحزمة آمنة للحفظ الشخصي، لكنها لا تغني عن حماية حساب البريد وManus وNetlify وGoogle Play عند فتحه.

أرسل فقط ملف ZIP الكامل عبر وسيلة خاصة. أخبر المطور أن يبدأ بملف `source-code-delivery-ar.md` داخل مجلد الأدلة، وألا ينشر ملفات البيئة أو الرموز السرية في GitHub.
