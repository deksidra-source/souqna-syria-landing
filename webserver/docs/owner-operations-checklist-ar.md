# قائمة تشغيل المالك — سوقنا سوريا

هذه القائمة مخصّصة لإدارة النسخة الأولية من «سوقنا سوريا» دون الحاجة إلى برمجة أو مشاركة كلمات المرور.

## ما يُشارك مع الجمهور

استخدم رابط صفحة الترويج الثابتة التالي في واتساب وفيسبوك وتيليغرام:

`https://monumental-faloodeh-e353bb.netlify.app/`

لا تشارك رابط لوحة المدير أو أي رابط ينتهي بـ `manus.computer`؛ هذه روابط خاصة أو مؤقتة.

## مراجعة الإدارة

عند توفّر رابط وصول موثوق للموقع التفاعلي، افتح `/admin` بالحساب المالك نفسه (`deksidra@gmail.com`). راجع الأقسام الثلاثة يوميًا في البداية:

| القسم | الإجراء المطلوب |
| --- | --- |
| البلاغات | راجع الإعلان أو الرسالة المبلّغ عنها، ثم غيّر الحالة إلى قيد المراجعة أو تم الحل. |
| تذاكر الدعم | اقرأ المشكلة، تواصل مع صاحبها بالوسيلة المناسبة، ثم غيّر الحالة بعد المعالجة. |
| طلبات حذف البيانات | لا تغيّر الحالة إلى تمّت المعالجة إلا بعد تنفيذ الحذف الفعلي والتحقق منه. |

## نسخ احتياطي آمن

احتفظ بنسخة كود خاصة في مكان لا يراه الآخرون. الحزمة المسلّمة باسم `souqna-syria-source-code.zip` لا تتضمن كلمات مرور أو مفاتيح. لا ترفعها إلى مستودع GitHub عام.

احتفظ كذلك بحسابات الدخول التالية باسمك، وفعل التحقق بخطوتين فيها:

| الحساب | سبب الاحتفاظ به |
| --- | --- |
| حساب Manus | إدارة المشروع والنسخ المحفوظة والموقع. |
| حساب Netlify | إدارة صفحة الترويج وتحديثها أو إيقافها. |
| البريد الإلكتروني | استعادة الحسابات واستقبال التنبيهات. |
| Google Play لاحقًا | نشر تطبيق Android باسمك عند توفر الرسوم. |

لا ترسل كلمة مرور أو رمز تحقق أو مفاتيح دفع عبر المحادثة أو البريد أو واتساب.

## ما يبقى مؤجلًا

تحتاج المنصة إلى نطاق خاص أو خدمة استضافة خادمية موثوقة قبل اعتماد رابط تفاعلي واسع؛ سبب ذلك خطأ اتصال SSL الذي ظهر على نطاق الموقع الحالي لدى بعض الشبكات. لا تعتمد رابط الاختبار المؤقت للترويج.

يبقى فتح حساب Google Play وبناء حزمة AAB الموقعة، واعتماد نصوص الشروط والخصوصية، وفتح حساب تاجر eCash أمورًا مؤجلة إلى حين توفر حسابات المالك والرسوم. تظل الإعلانات الأساسية مجانية إلى ذلك الوقت.
