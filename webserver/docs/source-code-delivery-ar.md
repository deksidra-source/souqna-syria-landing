# حزمة كود «سوقنا سوريا»

هذه الحزمة تحتوي على **الشيفرة المصدرية** للموقع والخادم وتطبيق الهاتف. لا تحتوي على قاعدة بيانات حية، أو كلمات مرور، أو رموز دخول، أو مفاتيح دفع، أو مجلدات الاعتمادات الكبيرة.

| المجلد | المحتوى |
| --- | --- |
| `souqna-syria-web/` | موقع React، خادم Express وtRPC، مخطط قاعدة البيانات Drizzle، الاختبارات والوثائق. |
| `souqna-syria-mobile/` | تطبيق Expo/React Native الأولي لأنظمة Android وiPhone. |

## أين يوجد كود الخادم؟

داخل `souqna-syria-web/server/`. أهم ملفين هما `routers.ts` الذي يعرّف إجراءات التطبيق وصلاحياته، و`db.ts` الذي يتعامل مع قاعدة البيانات. أما مخطط الجداول والترحيلات فيوجدان داخل `souqna-syria-web/drizzle/`.

## أين توجد واجهة الموقع؟

واجهة الويب داخل `souqna-syria-web/client/src/`. تحتوي `pages/` على الصفحات ومنها لوحة المدير `pages/Admin.tsx`، وتحتوي `components/` على العناصر المشتركة.

## أين يوجد كود تطبيق الهاتف؟

داخل `souqna-syria-mobile/`. نقطة الدخول الأساسية هي `App.tsx`، بينما توجد شاشات النشر والحساب والاتصال بالخدمة داخل `src/`.

## تشغيل الكود لاحقًا

يلزم جهاز يحتوي Node.js وpnpm. داخل كل مجلد شغّل أولًا `pnpm install` لتنزيل المكتبات، ثم راجع ملف `README.md` والإعدادات قبل تشغيل المشروع. الموقع الكامل يحتاج أيضًا إلى متغيرات تشغيل وقاعدة بيانات؛ هذه القيم **غير مرفقة عمدًا** لأنها حساسة ولا ينبغي إرسالها أو نشرها.
