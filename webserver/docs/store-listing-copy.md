## العربية

**الوصف المختصر:** تصفّح إعلانات سوريا للعقارات والسيارات والوظائف والخدمات والمستعمل.

**الوصف الكامل:**

> سوقنا سوريا منصة مبوبة تساعدك على اكتشاف الإعلانات في سوريا عبر أقسام العقارات والسيارات والوظائف والمستعمل والخدمات. ابحث بالكلمات أو القسم أو المحافظة، راجع تفاصيل الإعلان وصوره وموقعه التقريبي، واحفظ الإعلانات التي تهمك.  
> 
> يمكنك إعداد مسودة إعلان واختيار الصور والموقع من التطبيق. وتُفتح عمليات النشر وإدارة الإعلانات والرسائل المحمية في الموقع المنشور للمصادقة الآمنة. يدعم التطبيق العربية والإنكليزية والتركية.  
> 
> احترم شروط الاستخدام، ولا ترسل أموالًا أو وثائق حساسة قبل التحقق المباشر من الطرف الآخر والإعلان. يمكنك الإبلاغ عن الإعلانات أو الرسائل المخالفة وحظر المستخدمين غير المرغوب بهم.

## English

**Short description:** Browse Syrian listings for real estate, vehicles, jobs, services, and used goods.

**Full description:**

> Souqna Syria is a classifieds marketplace for discovering listings across Syria. Explore real estate, vehicles, jobs, used goods, and services. Search by keyword, category, or province; review listing details, photos, and approximate location; and save listings that matter to you.  
> 
> You can prepare a listing draft, choose photos, and select a location in the app. Secure publishing, listing management, and private messaging currently open in the published website for authenticated access. The app supports Arabic, English, and Turkish.  
> 
> Follow the Terms of Use. Do not send money or sensitive documents before verifying the other party and the listing directly. Users can report problematic listings or messages and block unwanted users.

## ملاحظات المراجعة المقترحة

استخدم هذه الملاحظات بعد استبدال بيانات الاختبار الحقيقية. لا تضع كلمة مرور حقيقية لشخص أو حسابك الشخصي.

> **Review access:** Some publisher-only actions open in the published Souqna Syria website to complete secure authentication. Use the dedicated review account provided in App Store Connect / Play Console. The public marketplace, search, languages, listing details, draft photo selection, and approximate-location selection are available directly in the app.  
> 
> **Moderation:** Users can report listings or messages, block another user in a private conversation, and submit support or data-deletion requests.  
> 
> **Permissions:** Photo access is requested only when the user chooses photos for a listing draft. Location access is requested only when the user chooses to set an approximate listing location.
